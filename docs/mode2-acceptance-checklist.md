## 1. T8 · 四条积分链路各验一例

> 目的:确认"PRO 骑手零金额"不会顺手把积分也清零。积分规则只看单量,
> 与金额无关——这四条各跑一次就能证明。

| # | 链路 | 怎么验 | 期望 |
|---|---|---|---|
| 1 | 完单积分 | 导入一天 PRO 报表(account=pro),挑 1 名 PRO 骑手 | 积分流水出现"完单"条目,分值与同单量的普通骑手一致;金额字段全 0 |
| 2 | 邀请奖励 | 用 PRO 骑手的邀请码注册 1 人并完成首单 | 邀请人拿到邀请积分,APP"我的邀请"里出现该人(姓名脱敏) |
| 3 | 合作商扫码 | PRO 骑手在合作商处扫一次码 | 积分到账,合作商侧计次 +1 |
| 4 | 等级/徽章 | 看 PRO 骑手的等级与徽章 | 按累计单量/在线时长正常升级,PRO 不享特殊也不被降级 |

- [ ] 四条全部通过
- [ ] 抽查:PRO 骑手的积分流水里 **没有任何金额字段**

## 2. T9 · 全链路演练(按人走一遍,约 30 分钟)

### 2.1 总部 HQ

- [ ] 骑手管理 → 打开批量抽屉 → 粘贴新 OL 名单 → 「导入名单并建档为 PRO」

- [ ] 建 1 个 PRO 班次(pool=pro),排班页时间旁出现 PRO 徽章
- [ ] 导入当日双报表:旧 OL(account=main)+ 新 OL(account=pro)
      → 对账页出现 PRO 小计 chip:`PRO R$X · N × R$12`
- [ ] 开屏配置 audience 选「仅 PRO」→ 普通账号打开 APP 不弹

### 2.3 站点

- [ ] 实时看板出现「应岗未上」红条(名册里有、快照里没有的人)

## 3.5 本批附加功能(A4/A5/倒扣)

- [ ] APP 配置页开启活动卡 → APP 首页出现,内容与配置一致
- [ ] 活动卡受众选「仅 PRO」→ 普通账号首页看不到
- [ ] 结束日期设为昨天 → 卡片消失(且**改手机日期也调不出来**,窗口在服务端判定)
- [ ] 活动卡链接填 `https://mall.meponto.com/...` → 在 APP 内打开且已是登录态
- [ ] 活动卡链接填任意站外域名 → **跳系统浏览器**,不在 APP 内加载
- [ ] 关闭活动卡 → APP 首页卡片真的消失(不是只在新装的机器上消失)
- [ ] 对账页红色「待扣」→ 抽屉里能看到人和天,逐条/整人核销
- [ ] 核销后:该条目消失、审计出现 `RIDER_DEDUCTION_SETTLED`、**导入表金额未被改动**
- [ ] 重复点核销 → 空操作,不会重复计数
