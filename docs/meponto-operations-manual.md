# MePonto 运营操作手册

> 受众：总部 / 加盟商 / 站点 / 供应商 / Partner 运营人员。
> 范围：各后台怎么用 + 端到端业务流程 + 日常操作清单 + 常见排查。
> 体系：**PontoSys**（运营系统）+ **PontoMall**（积分商城）。

---

## 一、系统总览与入口

| 角色 | 入口域名 | 主要职责 |
|---|---|---|
| 总部 HQ | `sys.meponto.com` | 全局运营、骑手、站点、财务、风控、分析 |
| 商城后台 | `mall.meponto.com/admin`（→ `/mall`） | 商品定价、订单审核、对账、分成、优惠券 |
| 加盟商 | `franchise.meponto.com` | 本商骑手/站点、结算确认、分成确认 |
| 站点（站长） | `ponto.meponto.com` | 班次、到货取货、本站销售记录 |
| 供应商 | `supplier.meponto.com` | 提报商品、改价、采购单、对账确认 |
| Partner（合作商） | partner 门户 | 用 partner 积分兑换、确认收货 |
| 公开商城（用户） | `mall.meponto.com` | 浏览/兑换（公开会员 + 骑手） |
| 骑手 App | `app.meponto.com` | 钱包、班次、商城、扫码、服务地图 |

**会员等级**：注册即「会员一级」（公开用户，无 99 ID）；绑定 99 ID 且有完单 → 自动升「会员二级（铜牌）」起，按完单升至银/金/钻。

## 三、各角色操作指南

### 1. 总部（sys.meponto.com）

- **看板 `/dashboard`**：全局概览。
- **骑手 `/riders` / 监控 `/rider-monitor`**：骑手档案、状态、风控标记。
- **用户/会员 `/members`**：全部会员（公开用户 + 骑手），按 99 ID 筛选「一级/二级」。
- **站点 `/pontos`**：站点（Ponto）维护，含经纬度、所属加盟商、是否可作取货点。
- **绩效 `/performance`**：导入 T+1 KPI/收入数据（Eastwind）。**收入表务必含「金额 / 行程收入 / Total diário」列**，否则结算金额会是 0。
- **考核 `/assessment`**：周 KPI 考核（见 §四.7）。
- **结算 `/wallet`**：自然周骑手结算 + PIX 提现审批（见 §四.6）。
- **商城后台 `/mall`**：定价、订单审核、对账、分成、优惠券（见下）。
- **风控/审计 `/support` `/access-control`**：工单、权限。

### 2. 商城后台 `/mall`（总部）

- **商品定价**：供应商提报的商品状态为「待定价」。在商品行填：① 积分价 ②（可选）+R$ 现金 ③ **加盟商分成 R$/单** → 点「定价上架」。
- **订单 / 高价值审核**：≥8000 分的兑换会「待审核」，在订单页 approve（放行/发券）或 reject（退积分+回补库存）。
- **优惠券**：新增/编辑/停用满减券（按等级、满 X 分、每人限用次数）。
- **供应链**：采购单（补货）、月度**供应商对账单**（生成→供应商确认→付款）。
- **销售分成**：月度**分成对账单**（生成→加盟商确认→付款，见 §四.5）。
- **混合支付 / 充值**：PIX 现金核销、骑手余额充值审核。
- **设置**：兑换上限（日次数/日积分/月积分/新账户）、高价值阈值、公司 PIX。

### 3. 加盟商（franchise.meponto.com）

- **结算 `/wallet`**：看本商自然周应结/已付/待付，标记付款给站点/骑手；审批本商骑手提现。
- **销售分成区（/wallet 顶部）**：设「站点分成 R$/单」；查看并**确认**总部生成的月度分成对账单。
- **考核**：看本商各站点周 KPI。

### 4. 站点 / 站长（ponto.meponto.com）

- **到货管理 `/mall/station`**：
  - 「在途」→ 货到点「确认到货」（markArrived）→ **自动给客户发站内信提醒取货**。
  - 「待取货」→ 客户到店「确认领取」（markPickedUp）。
  - 高价值待审单：等总部审核后才可确认到货。
- 本站销售记录在该页可见（经本站取货的所有订单）。

### 5. 供应商（supplier.meponto.com → /mall/supplier）

- **提报商品**：填名称、供货价 R$、配送周期、库存、面向对象（骑手/合作商/both）、类型、图片 → 提交（状态「待定价」，等总部定价上架）。
- **改自有未定价商品**：定价前可改/删；定价后只能走「改价申请」。
- **对账**：月度对账单（总部生成）→ 供应商**确认**（填收款 PIX）→ 总部付款。

### 6. Partner（合作商）

- **兑换**：用 partner 积分兑换；**实物取货只能在 Ponto**（系统按 partner 服务点最近 10 个 Ponto 供选）；虚拟商品即时发券。
- **积分来源**：骑手扫 partner 二维码，每 N 次服务发一次固定积分。
- 实物到 Ponto 后由站长履约。

## 四、核心业务流程（端到端）

### 1. 商品上架
供应商提报（待定价）→ 总部 `/mall` 定价（积分价 +可选现金 +加盟商分成）→ 上架（active）。

### 2. 兑换（用户/骑手/Partner）
storefront/app 选商品 → **选取货门店（只能 Ponto）** → 扣积分（+可选现金）→ 订单「在途」。
- 取货门店规则：骑手有归属站点→锁定；无站点→本加盟商站点；公开用户→任一；Partner→最近 10 个 Ponto。
- 风控：风控骑手禁兑；超日/月/新账户上限拦截；≥8000 分转人工审核。

### 3. 履约（无门店库存）
下单后 1~3 天配送到所选 Ponto → 站长「确认到货」（自动发站内信）→ 客户到店「确认领取」完成。
- 虚拟商品：即时发券，无需取货。
- 取消：仅「在途」可由用户自助取消 → 退积分 + 退现金 + 回补库存。

### 4. 供应链对账
总部 `/mall` 选月份「生成供应商对账单」（按 已取货订单 × 供货价）→ 供应商确认 → 总部付款。

### 5. 销售分成（两级，固定额）
① 总部按产品设「加盟商分成 R$/单」；② 加盟商设「站点分成 R$/单」。
**订单取货完成时自动计提**一条分成账：站点得站点分成，加盟商净得（产品分成 − 站点分成）。
月度：总部 `/mall`「生成分成对账单」→ 加盟商 `/wallet` 确认 → 总部付款。
> 注：分成按**取货月**归属；分成只对**有取货门店的实物订单**计提（虚拟券不计）。

### 6. 骑手结算与提现（/wallet）
自然周（周一–周日）按导入的日结算金额聚合「加盟商 → 骑手」。
- 「标记付加盟商」会按实付**比例分摊**到骑手；
- 骑手 App 发起 PIX 提现 → 总部/加盟商「已付款/拒绝」审批；
- **PIX 提现也会计入周台「已付」**（与骑手余额一致）。

### 7. 周 KPI 考核（/assessment）
按自然周、用各加盟商**真实日数据**聚合：完单/在线时长求和；**%TSH 按真实工时还原**（Σ在班时长/Σ签约时长）；AR/CAA 按完单加权。对照规则阈值给达标/未达标 → 佣金调整。纯展示，不影响结算。

### 8. 积分经济
- **获取**：完单自动积分、推荐/裂变（会员邀会员、邀 partner）、生日礼、partner 服务、人工调整。
- **消耗**：商城兑换（账本 spend）。
- **过期**：12 个月 FIFO 自动过期（留痕）。
- 账本 append-only，可审计。

### 9. 公开用户 / 会员
- 注册：`mall.meponto.com/register`（姓名+手机，可带 `?ref=` 邀请码）。
- 登录：同页「Entrar」用手机号登录。
- 升级：绑定 99 ID 后自动升二级。

### 10. 站内信
到货等事件自动给会员发站内信，会员在商城/ App 顶部「📬 Mensagens」查看，可标记已读。无需短信/WhatsApp。

## 五、日常操作清单

**每日**
- 站点：确认到货 / 确认取货；处理待取队列。
- 总部：高价值兑换审核；PIX 提现审批；混合支付核销。
- 绩效：导入 T+1 KPI/收入数据（确认含金额列）。

**每周**
- 总部：跑自然周骑手结算，标记付款；查看周 KPI 考核。
- 加盟商：确认本商结算 / 分成。

**每月**
- 总部：生成供应商对账单 + 销售分成对账单 → 催确认 → 付款。
- 供应商/加盟商：确认各自对账单。

## 六、常见问题排查

| 现象 | 原因 / 处理 |
|---|---|
| `/wallet` 有订单数、**结算金额为 0** | 导入的收入表缺「金额/行程收入」列 → 在 `/performance` **重新导入含该列的当周数据**。 |
| 销售分成不显示 / 为 0 | ① 产品没设「加盟商分成 R$」② 订单还没「取货完成」③ 取货门店未绑加盟商 ④ 加盟商记录不存在（先在 `/franchise` 建好）。 |
| 加盟商设不了「站点分成」 | 该加盟商需先存在于系统（`/franchise` 建档）。 |
| Partner 实物兑换提示「选择取货门店」 | 正常——Partner 实物必须选最近 Ponto（不发到自有店）。 |
| 公开用户注册后无法兑换 | 让其用 `/register` 的「Entrar」**手机号登录**后再兑换。 |
| 高价值订单卡在「待审核」 | 总部在 `/mall` 订单页 approve/reject。 |

## 七、合作伙伴 / 供应商账号开通与登录（重要）

> 在 `mall.meponto.com/crm` 添加合作伙伴**只是建档，不会自动生成登录账号**。必须单独开通。

**开通步骤（运营在 CRM 操作）**
1. CRM「添加合作伙伴」→ 填名称、类别（Supplier=供应商 / 其它=Partner）、联系人、电话等 → 创建。
2. 建议先把状态置为「活跃」。
3. 在该合作伙伴行点 **「开通账号」**，填他的**邮箱或手机号**（= 登录账号）。
4. 系统生成一个 **10 位一次性临时密码**，**弹窗只显示一次** → **当场复制交给对方**（系统只存哈希，事后无法找回）。

**账号角色与入口（按类别自动分配）**
| 类别 | 角色 | 登录后进入 |
|---|---|---|
| 供应商 Supplier | Supplier Admin | `supplier.meponto.com` → 供应链工作台 `/mall/supplier`（提报商品、改价、补货、对账） |
| 其它合作伙伴 | Partner Operator | partner 工作台 `/partner-points`（服务确认、Partner 积分） |

**对方如何进入系统**
- 打开对应门户域名的登录页，输入「账号（邮箱/手机）+ 临时密码」→ 登录后自动跳到工作台。
- 建议首次登录后改密码。
- **临时密码丢失** → 走密码重置，或用另一个 identifier 重新开通。

## 八、后台菜单去哪找（避免「找不到」）

不同门户侧边栏只显示**本门户配置的模块**，所以同一个功能在不同后台位置不同：

| 功能 | 总部 sys.meponto.com | 商城后台 mall.meponto.com |
|---|---|---|
| 用户 / 会员表 | ✅ 用户/会员 | ✅ 用户/会员 |
| 骑手档案 | ✅ 骑手档案 | —（在总部） |
| 积分经济（积分管理） | —（在商城后台） | ✅ 积分经济 |
| 商城工作台（定价/订单/对账/分成） | 看数据在「商城关键数据」 | ✅ 商城工作台 `/mall` |
| Partner 积分 / CRM | — | ✅ |
| 结算与提现 | ✅ | ✅ 商城财务 |
| 用户与权限（系统账号/角色） | ✅ 用户与权限 | — |

> 注：`/members`（用户/会员）此前漏接菜单，已补到总部 + 商城后台；积分经济一直在商城后台（旧线上版本可能未更新，部署后即出现）。
