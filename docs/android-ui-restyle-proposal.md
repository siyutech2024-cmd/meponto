# Android Rider App 年轻化改版方案(对比稿说明)

> 配套文件:`docs/android-ui-restyle-mockups.html`(浏览器打开,可切换 首页/商城,手机内容可滚动)
> 状态:方向对比阶段,未动任何代码。

## 一、现状为什么显"老"

当前 `android-rider-app` 是干净的 Material 3 + 语义 token 实现,问题不在工程,在视觉语言:

1. **通栏白卡一摞到底** — 首页 7 个 Panel 全部同宽、同色、同圆角(16dp)、同内边距,没有视觉节奏,像后台管理系统搬到手机上。
2. **品牌黄只是点缀** — 黄色只出现在小图标 chip 和小徽章上,页面主体是灰白+黑字,缺少品牌记忆点。
3. **信息密度过高、字号偏小** — 大量 11–14sp 文字行,缺少"大数字、大标题"的呼吸感,年轻向 App 普遍用超大数字+超短标签。
4. **没有情绪化元素** — 无插画、无 emoji/贴纸感图标、无渐变(仅会员卡一处)、无问候语场景化,整体是"工具",不是"伙伴"。
5. **顶栏是老式 title bar** — logo+标题+头像一行,等同于 2015 年的 ActionBar 结构。

## 二、三个候选方向(见对比稿)

| | A 活力外卖风 Energia | B 渐变玻璃风 Neon | C 清新圆润风 Soft |
|---|---|---|---|
| 参考 | iFood、美团骑手端 | Nubank、Revolut、游戏化 | Duolingo、新消费 App |
| 核心手法 | 品牌黄大面积头部下弯+卡片上叠、彩色图标宫格、大数字 | 暗底+霓虹渐变光斑、毛玻璃卡、发光数字、悬浮胶囊导航 | 大留白、28dp+超大圆角、马卡龙色块分区、黑色实心按钮 |
| 与现有 token 距离 | 中(浅色主题为主,黄升为主角) | 最近(现有暗色 token 直接演进) | 最远(新增 4–5 个 pastel token) |
| 烈日户外可读性 | 最好 | 弱 | 好 |
| 低端机性能 | 无风险 | 毛玻璃 blur 有成本(可降级为半透明) | 无风险 |
| 气质 | 效率、热情、"干活的劲儿" | 潮、游戏感、等级荣誉感 | 轻松、友好、"逛"的感觉 |

**倾向建议:A 为主、B 做点缀。** 骑手主场景是白天户外接单,A 的可读性和行业熟悉度最优;会员卡/等级/成就页可以借用 B 的渐变发光手法制造荣誉感,两者不冲突。

## 三、无论选哪个方向都会做的通用升级

- 顶栏改为「问候语 + 场景化副标题 + 头像」,去掉 logo 标题栏。
- 关键数字放大(28–42sp、FontWeight.Black),标签缩小,建立大小对比。
- 卡片分层:hero 卡(1 个)> 功能宫格 > 信息列表,打破"全部同级 Panel"。
- 图标从单色 Material icon 升级为「彩底圆角 chip + 更饱和的色」或 emoji 风格。
- 圆角体系上调:card 16→20/24dp,按钮全部胶囊化。
- 底部导航活性态加强(胶囊高亮或浮岛式)。
- 空状态/成功态补插画或大 emoji,增加情绪反馈。

## 四、落地路径与护栏(定稿后执行)

1. **Token 先行**:只改 `ui/theme/Theme.kt` 的 `MeColors`/`MeRadius`/新增 `MeGradients`,组件继续只引用语义 token(符合现有规范"never raw hex")。
2. **跨端同步**:`CLAUDE.md` 要求 Android 与 iOS `Theme.swift`、`docs/design-system.md` 保持 1:1 —— 定稿后需同批更新这两处,或在 PR 中声明临时例外与补齐计划。
3. **Feature flag**:新视觉建议挂 `ui.restyle.v2` flag 灰度(硬规则 #3)。
4. **改动顺序**:Theme.kt → Components.kt(Panel/StatTile/ActionRow/PrimaryButton)→ HomeScreen → MallScreen → 其余 Screen,单分支单模块,小步提交。
5. **验收**:每步 `npm` 侧不受影响,Android 侧以构建+截图对比验收;文案保持 zh/en/pt 三语(对比稿用葡语示意)。

## 五、v2 追加:对 v1 的自检与三个更新方向

配套文件:`docs/android-ui-restyle-mockups-v2.html`

对 v1 的批评:A 安全但平庸(与所有外卖 App 同质化);B 的玻璃拟态是 2021–22 遗产,2026 已显旧,且 blur 在低端机有性能成本;C 信息密度不足,不适合数据密集的骑手工具。三稿共同短板:仍是竖排卡片流,层次靠颜色而非**版式与字体**。

| | D · Material 3 Expressive | E · Bento 编辑风 | F · 街头运动风 |
|---|---|---|---|
| 核心手法 | 不对称混合圆角、52sp 超大数字、色调容器、分裂按钮、胶囊导航指示 | 不对称 Bento 网格分主次、超大编辑体大写标题、纸白+墨黑+黄三色 | 斜体重字、速度条纹、硬阴影、游戏 HUD 式等级/任务 |
| 为什么更年轻 | 跟随 Android 官方 2025–26 设计语言,"和系统一起新" | 2024–26 最主流布局趋势,自信、有态度、差异化最强 | 把跑单包装成运动竞技,情绪共鸣直达目标人群 |
| Compose 成本 | **最低**(M3 shapes/typography 原生支持) | 中(需 BentoGrid 组件+字阶) | 中(暗色 token 沿用,需 display 字体) |
| 风险 | 与 iOS 端视觉语言拉开差距 | 对内容质量要求高,空数据时显空洞 | 葡语长词排版难;财务页需冷静变体 |

**v2 建议:D 为骨架(官方、低成本、不过时),吸收 E 的 Bento 首屏布局和大字层次;F 的斜体+条纹只用在任务/成就等游戏化模块。**

## 六、v3 追加:高级感方向(含班次 Turnos 三屏)

配套文件:`docs/android-ui-restyle-mockups-v3.html`(首页 / 班次 / 商城 三屏切换)

前两轮"不高级"的病根:emoji 图标、大面积色块、圆角堆砌——这些手法是"可爱/热闹",不是"贵"。v3 换掉高级感的来源:

- **衬线大数字**(等级分 56sp、积分 48sp)承担视觉重心;
- **发丝线代替卡片边框**,列表不再是"一摞卡片";
- **9sp 大写+2.6px 字距的小标签**建立精致的次级层次;
- **品牌黄降饱和为香槟金 #E8C15A**,只给关键数字和状态点,越少越贵;
- **细线 SVG 图标**替换 emoji 与填充式 Material icon。

两个方向:**G · Noir 黑金静奢**(炭黑+香槟金,私人银行/黑卡气质,等级体系表现力最强,与现有 dark token 同族)和 **H · Gallery 画廊极简浅色**(象牙纸白+墨黑,烈日户外可读性最好,更适合日用)。建议 H 为日间默认、G 为深色模式——两者是同一套版式语言的明暗变体,可共用一套组件。

班次(slot)模块在 v3 中按 `ShiftsScreen.kt` 真实结构重排为时间轴:左列衬线时窗数字,发丝线+状态圆点(金=开放、绿=已确认、灰=满员),右侧名额分数;"我的日程"与免责说明保留。

## 七、v4 追加:巴西年轻人方向(Tropical / Noite 日夜双主题)

配套文件:`docs/android-ui-restyle-mockups-v4.html`(首页 / 班次 / 商城 三屏)

v3 的反馈是"颜色太单调"。v4 保留 v3 的版式骨架(56sp 大数字、明确层次、细线 SVG 图标),把色彩系统换成巴西新生代 App 的语言:

- **调色板**:热带绿 `#00A868` / 深丛林绿 `#0B5C3B` / 品牌黄 `#FFC400` / 荧光粉 `#FF4D8D` / 落日橙 `#FF6A3D` / 电紫 `#B14DFF` / 电蓝 `#2D6BFF` / 霓虹绿 `#4DE0A8`。饱和撞色是 Nubank/iFood 等巴西品牌的通用语言,刻意避开"国旗绿黄"俗套。
- **品牌图形**:科帕卡巴纳海滨步道(Burle Marx)波浪纹,贯穿 hero 卡、积分卡、日程卡,本土认同感强且有版权安全的抽象性。
- **色彩有语义**:KPI 三色块(黄/粉/蓝)、班次状态左边条(绿=开放、粉=危急、灰=满员)、任务进度双色——颜色多但每种颜色都有职责,不乱。

**I · Tropical Modernista(日间)**:米白底+撞色块+硬阴影按钮,烈日可读性优先。
**J · Noite(夜间)**:深紫夜底+落日橙粉渐变 hero+霓虹状态色,晚高峰场景。

**核心建议:I/J 共用同一套组件,做成日/夜双主题**(按时间或系统主题自动切换)。"白天热带、晚上落日"本身就是可传播的产品记忆点。落地时两套色板即 `LightMeColors`/`DarkMeColors` 的替换,与现有 token 架构完全兼容,只需扩充 4–5 个语义色位(secondary/tertiary/gradient)。
