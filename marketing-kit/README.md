## Regras de logo / Logo 规则

- **Fundo amarelo ou claro** → `meponto-logo-transparent.png` (M navy + "ponto" branco lê bem). 黄底/浅底用透明版。
- **Fundo escuro / avatar** → `meponto-icon-rounded.png` (o ícone tem fundo amarelo próprio). 深色底/头像用圆角图标。
- Nunca coloque o logo **colorido horizontal** sobre fundo escuro (o "M" navy some). 彩色横版勿放深色底。
- Não recolorir, girar, esticar nem adicionar sombra. 勿改色/旋转/拉伸/加阴影。

## Como usar / 使用说明

- Todos os `.png` estão prontos para publicar (Instagram, WhatsApp, impressão). 所有 PNG 可直接发布/打印。
- Código sempre em MAIÚSCULAS `MEPONTO99OL`; site em minúsculas `meponto.com`. 推广码全大写、官网全小写。
- Textos para o Brasil em Português. 巴西物料用葡语。
- Regras completas em `brand-guidelines.html`. 完整规范见品牌手册。
