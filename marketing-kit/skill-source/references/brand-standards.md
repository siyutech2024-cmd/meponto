# MePonto brand standards — detail reference

## Color pairings (what sits on what)

| Background | Text | Accents |
| --- | --- | --- |
| Yellow `#FFD400` | Navy `#12172A` | navy panels; dark-gold `#5B4F13` for tertiary lines |
| Navy `#12172A` | White `#FFFFFF` | yellow `#FFD400` for eyebrow/code/links; gray `#C8CCD8` body |
| Navy panel on yellow | White title | yellow number/code, gray `#C8CCD8` description |
| White (documents) | Navy | yellow only for buttons/highlights — never yellow text on white |

Functional colors (status content only, never decorative):
success `#3FB984`, warning `#E0A500`, danger `#E5484D`.

## Typography scale (1080-wide reference)

| Role | Size | Style |
| --- | --- | --- |
| Eyebrow | 26–32 | Bold, uppercase, tracking +4…7 px |
| Headline | 96–120 | Black/Bold, uppercase, tight leading (~1.02) |
| Subhead | 34–40 | Bold, sentence case |
| Bullet | 33–38 | Bold |
| Code | 46–92 | Bold Italic, uppercase |
| Website | 40–50 | Bold Italic, lowercase |
| Caption | 20–26 | Bold or Regular |

Font stack: Arial Black / Arial Bold → Liberation Sans Bold (Linux) →
Helvetica. Brand name and promo code always **bold italic**. Chinese:
PingFang SC / Microsoft YaHei / Noto Sans CJK. Free web equivalents:
Inter (body), Archivo/Montserrat (headlines).

## Copy tone (Portuguese)

Direct, confident, practical — talking to people who want to
empreender e entregar. Short sentences, action verbs first:
*Cadastre-se, Comece, Ganhe, Troque, Entre.*

Approved phrases:
- Eyebrows: FRANQUIA DE ENTREGA · OPORTUNIDADE DE FRANQUIA ·
  ENTRE PARA A REDE · OFERTA DE LANÇAMENTO
- Headlines: SEJA UM FRANQUEADO · USE O CÓDIGO · GANHE PONTOS
- CTA: QUERO SER FRANQUEADO · Cadastre-se em meponto.com
- Code label: CÓDIGO DE VANTAGEM (always this exact label)
- Benefits pool: Rede pronta de entregadores e pontos · Sistema, marca
  e treinamento completos · Comece a operar em poucos dias · Renda
  recorrente e escalável · Marca, sistema e suporte prontos

Never promise specific earnings figures or guaranteed income — keep
benefit claims qualitative unless headquarters supplies numbers.

## Compliance checklist (run before delivering)

- [ ] Correct logo file for the background; not redrawn or recolored
- [ ] Code reads exactly `MEPONTO99OL`, uppercase, in a highlighted panel
      labeled CÓDIGO DE VANTAGEM
- [ ] `meponto.com` visible, lowercase, no https://
- [ ] Yellow #FFD400 + navy #12172A palette; no off-brand hues
- [ ] One language per label; Portuguese for Brazil-facing copy
- [ ] Margins ≥ ~7% short side; no text touching edges
- [ ] Rendered image visually inspected before delivery
