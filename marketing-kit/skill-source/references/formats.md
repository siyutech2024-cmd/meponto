# MePonto material formats — sizes & layout recipes

Every recipe assumes the yellow-dominant default. For a dark variant,
swap canvas to NAVY, text to white/yellow, and use the icon badge
(`meponto-icon-rounded.png`) instead of the horizontal logo.

Margins: ~7% of the short side (e.g., 72–80 px on a 1080 canvas).

## Instagram / Facebook square post — 1080×1080

Top-left: horizontal logo, width ~440 px.
Then: eyebrow (tracked uppercase, 26–30 px) → headline (2 lines,
96–110 px bold uppercase, key word may sit alone on its line) →
3 benefit bullets (33–38 px, navy dots) → bottom row: code panel
(~640×120, navy, label + code) on the left, website block on the right
("Cadastre-se em" small + `meponto.com` italic bold 46 px).

## Instagram story / WhatsApp status — 1080×1920

Same vertical flow as the square post but roomier: logo width ~520 px,
headline up to 3 stacked lines at 112–120 px, code panel ~920×170,
then a full-width CTA pill (navy, radius = half height, yellow bold
uppercase text ~52 px, e.g. "QUERO SER FRANQUEADO"), then centered
website + secondary line at the bottom.

## Link/share banner (OG, ads) — 1200×628

Logo top-left ~360 px wide. One eyebrow + two-line headline (64–70 px).
Bottom row: code panel (~470×86) left, CTA pill with `meponto.com`
right. No bullets — banners are glanced at, keep them sparse.

## A4 poster / flyer — 1240×1754 (150 dpi) or 2480×3508 (300 dpi print)

Header: logo ~470 px wide. Hero: eyebrow + 2-line headline (~110 px)
+ one supporting sentence. Middle: "POR QUE MePonto?" + 2×2 grid of
navy cards (500×150 each: number in yellow italic, title white bold,
one-line description gray). Lower: "COMO COMEÇAR" numbered steps on
the left, navy code panel on the right. Footer: full-width navy band
(~136 px tall): `meponto.com` yellow italic + secondary channels left,
"Fale conosco:" + email right.

## Business card — 1050×600 (front), 300 dpi

Front: yellow, horizontal logo centered or left, franchisee name
(navy bold 60 px) + role (30 px), contact lines bottom (phone,
email, city). Back: navy, icon badge centered, `meponto.com` yellow
italic below.

## WhatsApp profile / avatar — 512×512

Use `meponto-icon-rounded.png` as-is, or centered at 80% on a navy
canvas. Never the horizontal logo (it becomes unreadable at avatar size).

## Roll-up banner / X-stand — 850×2000 (screen proof; ×4 for print)

Vertical: logo top (~600 px wide), headline stack, 3–4 bullets,
code panel, CTA pill, footer band. Leave the bottom 15% low-density
(often hidden by the stand mechanism).

## Custom sizes

Scale the 1080-square recipe proportionally by the short side, and keep
the type hierarchy: eyebrow ≈ 0.55× bullet size; headline ≈ 3× bullet
size; code ≈ 1.4× bullet size.
